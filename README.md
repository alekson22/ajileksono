## 🚀 Deploy to Vercel
Website ini menggunakan arsitektur static HTML5, CSS3, dan vanilla JavaScript modern yang siap di-deploy langsung ke Vercel tanpa build step tambahan:
1. Hubungkan repository GitHub ini di dashboard Vercel (`Import Git Repository`).
2. Framework Preset: **Other** (Root directory `./`).
3. Klik **Deploy**.
